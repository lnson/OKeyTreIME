## Tiếng Việt

**ÔKêyTre** ra đời nhằm cải thiện trải nghiệm gõ tiếng Việt trên Mac. Các tính năng chính bao gồm

### 1. Kiểu gõ
- **Hỗ trợ nhiều kiểu gõ**, gồm có **Telex**, **VNI** và **VIQR**.
- **Bỏ dấu tự do**: Cho phép gõ dấu thanh và dấu mũ/móc ở bất kỳ vị trí nào trong âm tiết.
- **Khôi phục nhanh từ gốc (gõ tiếng Anh)**: Nhấn đồng thời **Shift Trái + Shift Phải** để khôi phục từ hiện tại về đúng chuỗi kí tự đang gõ và tạm ngưng biến đổi tiếng Việt cho đến khi sang từ mới.
- **Tối ưu hoá việc sửa lỗi chính tả**: Bạn có thể quay lại để sửa chữ trên cùng một dòng. Với các ứng dụng có trợ năng, bạn có thể sửa từ bất kì bằng việc đặt con trỏ vào từ đó.

### 2. Tự động sửa lỗi chính tả:
Có thể bật/tắt riêng từng quy tắc trong mục **Tự động sửa lỗi**:
- **Tự động áp dụng quy tắc đặt dấu thanh mới**: `oà`, `uỳ` thay vì `òa`, `ùy`.
- **Tự động sửa lỗi**: 
  - `"ng + i/e"` thành `"nghi/nghe"`
  -`"ngh + a/o/u"` thành `"nga/ngo/ngu"`
  - `"ưo"` thành `"ươ"`.

### 3. Tích hợp hệ thống
- **Chạy hoàn toàn trên menu bar**: Giống hoàn toàn với trải nghiệm bàn phím của Mac.
- **Tích hợp với bàn phím của Mac**: Tự động tắt dể tránh xung đột khi nhiều kiểu gõ khác nhau cùng chạy.

## English

**ÔKêyTre** is an Input Method Engine (IME) aimed to improve the Vietnamese typing experience on Mac. Key features include:

### 1. Input Methods
- **Multiple input styles**, including **Telex**, **VNI**, and **VIQR**.
- **Free-order diacritics**: Type tone marks and vowel modifiers at any position within a syllable.
- **Instant raw-word restore (English typing)**: Press **Left Shift + Right Shift** simultaneously to restore the current word to its raw typed characters and pause Vietnamese transformations until the next word.
- **Streamlined word editing**: Move back to edit words on the same line. In Accessibility-enabled apps, you can edit any word simply by placing the cursor inside it.

### 2. Auto-Correction
Each rule can be toggled individually under **Auto-Correction**:
- **Automatically apply modern tone placement**: `oà`, `uỳ` instead of `òa`, `ùy`.
- **Auto-correct spelling**:
  - `"ng + i/e"` to `"nghi/nghe"`
  - `"ngh + a/o/u"` to `"nga/ngo/ngu"`
  - `"ưo"` to `"ươ"`.

### 3. System Integration
- **Lives entirely in the menu bar**: Matches the native Mac input source experience.
- **Integrates with Mac keyboard layouts**: Automatically deactivates to avoid conflicts when multiple input methods are active.
